# Security policy

A bug in a Cashu Card repository can lose the money on a card, so reports are welcome and taken seriously.

## Reporting a vulnerability

Report it privately through the affected repository's security advisories: open its **Security** tab and choose **Report a vulnerability**. That creates a private advisory that only the maintainers can see. Please keep vulnerabilities out of public issues, pull requests and discussions.

Include as much of this as you can:

- what the vulnerability is and what it puts at risk;
- how to reproduce it (a proof of concept, the affected commit or command);
- a suggested fix, if you have one.

## What to expect

Every report is read, and we keep you informed while we investigate and fix it. Please allow a reasonable window for a fix before disclosing it publicly.

A repository with its own `SECURITY.md` follows that file instead of this one.
